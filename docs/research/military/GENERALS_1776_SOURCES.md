# GENERALS_1776_SOURCES

Reference date: **1776-01-01**

This register closes the historical-research package for the post-CLEANUP-2D-3 land-formation baseline.
It separates **identity confidence** from **formation-mapping confidence**: a senior military office can be certain
while mapping it to a Victoria 3 theatre aggregate remains only medium-confidence.

## Method

Source priority: official archives and contemporary official lists; government gazetteers and digitised public-domain
compilations; specialist historical encyclopedias and academic histories; broad secondary material only as corroboration.

A blank historical name in the MASTER does **not** mean no commander existed. It means no candidate met the
date + military-role + formation-mapping + source threshold without inventing precision.
