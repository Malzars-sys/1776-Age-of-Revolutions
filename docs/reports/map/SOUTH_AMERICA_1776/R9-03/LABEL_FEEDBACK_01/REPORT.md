# R9-03 — distinction du nom du port

Le joueur a observé en jeu deux libellés identiques. Les clés de hubs avaient toutes reçu le nom de Sacramento. La seule clé du port devient « Port de Sacramento » / « Port of Sacramento » ; celle de la ville reste inchangée. Aucun propriétaire, pixel, habitant ou bâtiment modifié.

Deux lignes de localisation changées, BOM et parité FR/EN conservés. Le manifeste courant combine les empreintes initiales avec cet amendement ; le manifeste original et la preuve précédente sont conservés.
