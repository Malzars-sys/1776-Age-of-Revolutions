# Test joueur — aucune installation occidentale nouvelle

Cette passe n'a modifié aucun fichier fonctionnel : aucun nouveau test moteur n'est requis pour recevoir son diagnostic. Elle ne fournit aucun reçu humain.

Le test restant utile est le [protocole groupé prussien déjà livré](../PRUSSIA_POLAND_2026_11_05/PLAYER_TEST_PROTOCOL.md), qui couvre les installations polono-prussiennes et saxonnes encore en attente. Il conserve son périmètre exact ; cette étude de l'ouest ne l'étend pas.

Les images `HYPOTHESES_NOT_INSTALLED.png` et les 39 cellules candidates de Berg ne sont pas visibles dans le jeu, puisqu'elles n'ont pas été installées. Aucune validation de frontières occidentales n'est à déduire d'un simple mois sans crash dans la configuration actuelle.

Si un correctif occidental est installé plus tard : préparer alors un protocole borné aux territoires effectivement changés et aux témoins protégés, en nouvelle partie 1776, avec vérification des propriétaires, repères, populations, bâtiments, PM et unités, puis simulation, sauvegarde/rechargement. Ne créer `PASS_RUNTIME_USER_VALIDATED` qu'après confirmation explicite du joueur.
