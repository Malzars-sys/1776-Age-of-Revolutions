# MAP2O — test en nouvelle partie

Le lot complet reste partiel. Le correctif côtier installé peut être testé séparément après PASS statique. Aucune validation moteur n'est revendiquée.

1. Lancer une **nouvelle partie** au 1er janvier 1776 ; une sauvegarde existante ne recharge pas automatiquement les propriétaires historiques.
2. Inspecter le port natif d'Emden et toute la province côtière xF9DCA2 : PRU, subdivision prussienne de STATE_HANNOVER. Le nom du grand État peut rester Hanovre.
3. Vérifier l'accès maritime et la construction portuaire possible dans cette subdivision ; aucun niveau de port n'a été ajouté par le correctif.
4. Vérifier la population et l'économie : 142 528 habitants déplacés dans la subdivision PRU, aucune création de population ou bâtiment. Contrôler les éventuels effets d'emploi, de marché et de capacité administrative.
5. Vérifier les couleurs voisines OLD, NET, HAN, Münster et les possessions prussiennes antérieures. Pas d'annexion de Jever/Varel/Kniphausen. Leur représentation distincte n'est pas annoncée comme terminée.
6. Ouvrir le journal impérial et la carte impériale : même étendue ; titulaire légitime PRU pour ce RGB. Une demande de rétrocession ne doit pas considérer la Prusse comme détentrice illégitime d'Emden.
7. Contrôle rapide Wismar, Neukloster, Poel et Poméranie suédoise : modifications MAP2N/R9 conservées.
8. Laisser passer un mois. Signaler crash, erreur de propriétaire ou province non possédée, disparition de bâtiment, incohérence de population, problème d'accès maritime ou clé brute.

Ne marquer PASS_RUNTIME_USER_VALIDATED que pour les éléments réellement inspectés après compte rendu du joueur. Cela ne certifie pas toutes les frontières historiques.
