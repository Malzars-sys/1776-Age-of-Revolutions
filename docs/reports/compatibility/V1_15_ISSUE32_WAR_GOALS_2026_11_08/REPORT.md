# Issue 32 — current territorial enforcement and infamy

Status: **IMPLEMENTED_READY_FOR_RUNTIME_VALIDATION**. Installed on 2026-11-08 in the regular local mod. Engine execution and maintainer acceptance are pending. The request was to complete #32 before the grouped engine test with #28.

## Problem and resulting rules

Three old same-path war-goal overrides hid the native 1.15 territorial mirror rule. Adding `mirrored_wargoal = { method = territorial }` allows their occupation timers to enforce the goal during a continuing war, with the corresponding retake/liberation goal generated by the engine. This is a configuration correction; no failed conflict has been reproduced by the agent.

Annex Country and Conquer State also kept the old population-scaling infamy formula. They now call the native country/state infamy values, retaining the subject multipliers and the mod's imperial protections. Unification remains zero-infamy. No country setup or diplomatic-play definition is changed.
