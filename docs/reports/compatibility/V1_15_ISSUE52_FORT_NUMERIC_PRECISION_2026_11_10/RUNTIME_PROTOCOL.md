# Vérification moteur — mission 52

1. Redémarrer le jeu avec le mod courant. Vérifier les nouveaux diagnostics de
   démarrage : les trois erreurs `Malformed token` visant le fichier des coûts
   de fortification doivent avoir disparu, ainsi que l'avertissement BOM du
   fichier japonais. Les anciennes captures restent conservées ; aucune autre
   erreur préexistante n'est déclarée résolue par ce correctif.
2. Dans un État intérieur où un fort terrestre est autorisé, inspecter le
   modificateur d'extension d'un fort existant : environ −18,18 %, −30,77 %,
   −40 % ou −47,06 % suivant les niveaux déjà construits. Lancer une extension
   et vérifier que le palier s'applique. Les points requis affichés restent 900 ;
   les coûts effectifs sont obtenus par une progression plus lente.
3. Vérifier qu'un autre type de bâtiment ne reçoit pas cette pénalité. Le plafond
   de cinq niveaux et les PM de garnison doivent conserver leur comportement.

Le petit écart de quelques centièmes de point n'a pas besoin d'être mesuré par
le joueur. Aucun nom de sauvegarde ni relevé précis de date n'est demandé.
Un retour indiquant si les erreurs ont disparu et si l'extension fonctionne
suffit pour l'acceptation de ce lot. La simulation complète des files et des
callbacks reste qualifiée dans le protocole initial de fortification.
