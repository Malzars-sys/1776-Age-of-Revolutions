# Lot 23 — révision 2 : Corps du génie

**Aperçus seulement, pas encore intégrés.** Le joueur a accepté le concept du théodolite ; cela n'est pas une validation de l'image finale ni une demande d'intégration.

Le gabion est remplacé par un **théodolite ancien en laiton sur un trépied en bois**. Une lunette, un cercle horizontal, un arc vertical et une boussole forment un seul appareil. Aucun plan ni table à dessin : l'icône de Topographie militaire existante reste distincte et inchangée.

Les Services vétérinaires et l'Artillerie à cheval conservent exactement leurs masters initiaux, sans régénération ni retouche. Les empreintes sont contrôlées.
