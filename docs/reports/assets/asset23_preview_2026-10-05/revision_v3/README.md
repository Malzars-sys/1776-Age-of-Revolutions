Version conservée pour traçabilité, remplacée par la [révision 4](../revision_v4/README.md) : le petit Figaro répété devient Allgemeine Zeitung. La sélection active est indiquée dans le dossier parent.

La demande précise maintenant de vrais noms de publications, reconnaissables, au lieu de bandeaux abstraits. Les quatre titres retenus sont Le Figaro, Le Constitutionnel, National Intelligencer et 京報 (Jing Bao). Ils sont adaptés typographiquement dans la composition en éventail, sans recopier un logo actuel ni un article.

Les noms sont authentiques ; ce groupement et ses formats sont conceptuels, pas une reconstitution d'une collection précise. 京報 représente l'information imprimée de la cour Qing, non un quotidien commercial moderne.
