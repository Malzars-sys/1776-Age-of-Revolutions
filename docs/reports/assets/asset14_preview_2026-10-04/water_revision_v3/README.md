# Irrigation — correction V3

Édition avec imagegen intégré (`BUILTIN_IMAGE_GEN`) ; aperçu seulement, non intégré.

L’ancienne eau en arche est remplacée par un écoulement qui sort d’un coude en laiton tourné vers le bas. La bouche reste visible et l’eau tombe directement depuis l’intérieur de l’ouverture. Le reste du design de la pompe est conservé ; l’élevage et le drainage V2 restent exactement inchangés.
