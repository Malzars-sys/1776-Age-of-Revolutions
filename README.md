# 1776 - Age of Revolutions Fork

Unofficial continuation and compatibility fork of **1776 - Age of Revolutions, Total Conversion Mod** for Victoria 3.

## Steam Workshop

**Age of revolution /Fork**

https://steamcommunity.com/sharedfiles/filedetails/?id=3780935876

Tested with **Victoria 3 1.13 / The Great Wave**.

## About this fork

This project ports and maintains the original 1776 total-conversion scenario on modern Victoria 3 versions while preserving its historical 1776 starting point.

Current work includes:

- Victoria 3 1.13 / The Great Wave compatibility
- restored and corrected 1776 country and map setup
- updated scripts, events and selected journal content
- historical objective presentation and period flags
- Battle for India
- Age of Revolutions
- Imperial Rivalries
- Mercantile Republics
- Learn the Game
- custom Trafalgar loading screen
- Washington Crossing the Delaware frontend
- custom menu music
- improved French and English narrative localisation

## Long-term direction

Planned work includes:

- deeper country-specific historical content
- more journals, events and situations
- a technology and industrial progression better suited to a 1776 start
- more historically differentiated navies
- continued economic, institutional and military balancing
- continued localisation and visual improvements

These are development goals, not promises for a particular release date.
